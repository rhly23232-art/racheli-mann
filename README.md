# רחלי מן – צילום מקצועי

אתר תדמית לצלמת בירושלים: גלריות לפי תחום, המלצות, שאלות נפוצות, טופס פניות ופאנל ניהול.

- `src/` – קוד המקור, מחולק לפי חלקים (css / html / js), ושכבת נתונים מוחלפת ב-`src/backend/`.
- `build.py public` – בונה את האתר הציבורי לתיקייה `public/` (Supabase + GitHub Pages).
- `build.py` – בונה גרסת תצוגה ל-claude.ai.
- `supabase/schema.sql` – טבלאות, הרשאות ואחסון התמונות.
- `site.config.json` – כתובת האתר ופרטי החיבור הציבוריים ל-Supabase.

ניהול האתר: בתחתית העמוד „כניסת מנהלת", או הוספת `#admin` לכתובת.
